## 🚀 Cara Menjalankan Secara Lokal

Pastikan [Node.js](https://nodejs.org/) telah terinstal di komputer Anda:

```bash
# 1. Masuk ke direktori proyek
cd d:/KAOS

# 2. Jalankan server lokal
node dev-server.js

# 3. Buka browser pada alamat:
http://localhost:3000/
```
